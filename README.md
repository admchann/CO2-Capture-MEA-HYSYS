# CO₂ Capture from NGCC Flue Gas Using MEA Absorption

> **Level 1 Process Engineering Project**  
> **Status:** 🟡 Stage 3 — Process Design Basis Complete

---

## 📌 Project Overview
This project investigates the simulation and process analysis of carbon dioxide capture from Natural Gas Combined Cycle (NGCC) flue gas using monoethanolamine (MEA) absorption in Aspen HYSYS. 

The goal of this independent study is to progressively demonstrate core chemical and process engineering skills, moving from literature benchmarks to full process simulation, sensitivity analysis, and engineering evaluation.

---

## 🎯 Project Objectives
The primary objectives of this project include:
* Developing a foundational understanding of post-combustion carbon capture processes.
* Modeling thermodynamic properties, mass/energy balances, and phase equilibria for dilute CO₂ streams.
* Constructing an equilibrium-stage simulation model in Aspen HYSYS.
* Analyzing key operating variables (e.g., L/G ratio, reboiler duty, solvent concentration) via sensitivity analysis.
* Evaluating engineering assumptions, simplifications, and limitations relative to industrial realities.
